# Meccanica statistica

Knowledge base personale di studio sulla meccanica statistica, mantenuta con Claude Code secondo le regole di [`CLAUDE.md`](CLAUDE.md).

## Struttura

- `raw/` – fonti originali: libri in `raw/libri/<materia>/`, appunti e articoli in `raw/appunti/`
- `wiki/` – articoli markdown in stile Obsidian; l'ingresso è [`wiki/indice.md`](wiki/indice.md)
- `output/` – report, confronti e risposte puntuali
- `.testo/` – testo dei PDF estratto pagina per pagina
- `scripts/` – strumenti, tra cui `libro.py` per preparare e cercare nei PDF
- `sito/` – il sito costruito a partire dalla wiki
